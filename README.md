# LLFA Quality Works

Landing page for **LLFA Quality Works** — a professional landscaping company.

## Structure
- `index.html` — the landing page (hero, services, why-us, process, gallery, reviews, quote form)
- `css/styles.css` — all styles (green nature palette, responsive)
- `js/main.js` — nav toggle, animated stat counters, quote-form handling
- `assets/` — drop your own photos/logo here

## Run locally
Open `index.html` in a browser, or serve it:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000

## To customize
- Replace placeholder **phone, email, and service area** in the Contact section of `index.html`.
- Swap the gallery color tiles for real project photos.
- Replace the placeholder reviews with real customer testimonials.
- The quote form currently shows a confirmation only — connect it to a backend or form service (e.g. Formspree) to receive submissions by email.
